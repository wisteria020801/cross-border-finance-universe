# 金融知识宇宙 Cross-Border Finance Universe

> 永久免费、手机即开即用、像 App 一样的金融知识图谱。

---

## 当前状态：已上线

**线上地址：** https://cross-border-finance-universe.vercel.app

手机 Safari 打开 → 分享 → 添加到主屏幕，体验和原生 App 一致。

---

## 项目概况

| 项 | 说明 |
|---|------|
| 技术栈 | 纯 HTML + CSS + JavaScript（零依赖、零构建） |
| 部署方式 | Vercel 自动部署（push 到 GitHub 即触发） |
| PWA 支持 | ✅ 离线可用、可添加到主屏幕 |
| AI 问答 | ✅ 离线 TF-IDF 检索引擎，无需 API Key |
| 节点数量 | 88 个知识节点，10 大模块 |

---

## 文件结构

```
cross-border-finance-universe/
├── index.html        ← 主应用（全部代码在这一个文件里）
├── manifest.json     ← PWA 配置
├── sw.js             ← Service Worker（离线缓存）
├── icon.svg          ← App 图标
├── vercel.json       ← Vercel 部署配置
├── readme.md         ← 本文件
├── prd.md            ← 产品需求文档
├── architechture.md  ← 架构设计
├── roadmap.md        ← 路线图
├── style guide.md    ← 样式规范
└── trae prompt.md    ← 开发提示词
```
